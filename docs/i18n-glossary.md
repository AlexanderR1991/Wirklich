# Philosophisches DE/EN-Glossar · Philosophical DE/EN Glossary

**Editorial draft · 7 November 2026.** This is a proposed terminology convention, **not** an independently reviewed philosophical translation. An English word may need a different rendering in a specific argument. Changes must explain the distinction, not merely replace a string.

**Leitregel / Guiding rule:** Eine sprachliche Übereinstimmung beweist keinen Konsens über die Sache. / Matching words do not establish agreement about the underlying claim.

| Deutsch | Preferred English | Grenze / Editorial distinction |
| --- | --- | --- |
| Wahrheit | truth | Not the same as certainty, majority belief or approval. / Nicht Gewissheit, Mehrheit oder Zustimmung. |
| Wirklichkeit | reality | What is the case, not what one wishes to be the case. / Nicht bloß die gewünschte Deutung. |
| Überzeugung | belief / conviction | A held position, not automatically justified. / Kein automatischer Beleg. |
| Erkenntnis | knowledge / warranted insight | Choose by argument; never imply demonstrated knowledge when describing a hypothesis. / Hypothesen nicht als Wissen ausgeben. |
| Begründung | justification / reasoning | Reasons offered for a claim; not necessarily a formal proof. / Nicht automatisch ein Beweis. |
| Beleg | evidence / supporting source | Source quality and relevance must be examined. / Qualität und Geltungsbereich prüfen. |
| Beweis | proof | Reserve strict proof for formal derivation; in empirical contexts specify evidential support. / Formale Ableitung von empirischer Stützung unterscheiden. |
| Hypothese | hypothesis | Testability and uncertainty matter. / Prüfbarkeit und Unsicherheit markieren. |
| These | thesis / claim | State scope and type of claim. / Geltungsbereich und Aussageart angeben. |
| Konsens | consensus | Recorded, reasoned agreement, **not** truth, unanimity, or vote count. / Nicht Wahrheit oder bloße Stimmenmehrheit. |
| Zustimmung | agreement / assent | An act of endorsement; does not establish validity. / Keine Validierung. |
| Dissens | disagreement / dissent | May remain justified and visible; not a system error. / Kann bestehen bleiben. |
| Gegenargument | counterargument / objection | Prefer the strongest fair version. / Stärkste faire Lesart prüfen. |
| Prüfung | examination / scrutiny / review | Not always verification or certification. / Nicht pauschal „proof“ oder „certification“. |
| fachliche Prüfung | expert review / subject-matter review | Only state completed review when it actually occurred. / Keine Freigabe erfinden. |
| Erkenntnisreife | evidential maturity / review maturity | A revisable register level, **not** a truth score. / Kein Wahrheitswert. |
| Aussageart | claim type | Empirical, formal, normative, interpretive, metaphorical tests differ. / Verschiedene Prüfmaßstäbe. |
| normative Aussage | normative claim | Requires stated values and perspectives; not laboratory proof. / Werte offenlegen. |
| Selbstkorrektur | self-correction | Recorded response to better reasons, not automatic concession. / Keine automatische Übernahme jedes Einwands. |
| Revisionsbedingung | revision condition | What would prompt reconsideration; do not promise an automatic change. / Anlass zur erneuten Prüfung. |
| Menschenwürde | human dignity | Normative commitment, not a measured empirical effect. / Normativer Maßstab. |
| Selbstbestimmung | agency / self-determination | Specify individual autonomy versus decision-making power as needed. / Kontext beachten. |
| Mustererkennung | pattern recognition / cross-domain connection | A proposed analogy still needs fresh validation. / Analogie ist kein Beweis. |
| philosophischer Motor | philosophical inquiry framework | A metaphor for a revisable process, not a physical engine or a validated intelligence layer. / Metapher, kein Naturgesetz. |

## False friends / Kritische Unterschiede

1. **Truth ≠ consensus.** Auch breite Einigkeit ersetzt keinen tragfähigen Grund. / Even broad agreement cannot establish truth.
2. **Evidence ≠ proof.** Empirical support depends on method and scope; formal proof depends on definitions and valid derivations.
3. **Review ≠ independent certification.** A documented editorial check is not a peer-reviewed scientific result.
4. **Philosophical unity ≠ forced reconciliation.** Legitimate value conflicts and disagreements may remain.
5. **Translation coverage ≠ translation accuracy.** Automated tests check structure and missing fields, not conceptual equivalence.

## Translation review / Übersetzungsreview

For a terminology change: link the German source and immutable revision, identify the current English text, explain the philosophical difference, propose corrected wording and an opposing interpretation, then open a PR or the [translation issue template](../.github/ISSUE_TEMPLATE/uebersetzung.yml). A named human reviewer must record the source commit, date and review link in [the release register](../public/i18n/review-register.v1.json) before any entry may be called *reviewed*. The reviewer may be the maintainer, but then the review is **not independent**. The public status must not suggest otherwise.
